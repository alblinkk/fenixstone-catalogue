# NORD — каталог

Готовый статический сайт-каталог на HTML, CSS и JavaScript.

## Файлы
- `index.html` — структура сайта
- `style.css` — дизайн
- `script.js` — товары, поиск, фильтры и модальное окно

## Как изменить товары
Открой `script.js` и измени массив `products`.

Сайт не требует базы данных или сервера и подходит для GitHub Pages.
